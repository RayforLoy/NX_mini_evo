# 追加功能与优先级

优先顺序以当前证据和依赖安排；表中没有任何尚未验证功能被承诺为可刷版本。P0 为第一版前置条件，P1 为首版，P2 为后续候选，P3 为投入较大的探索。

| 优先级 | 功能 | 当前证据／收益 | 主要依赖与下一步 |
| --- | --- | --- | --- |
| P0 | 备份和恢复、启动映射 | 已识别的是 updater，完整恢复未知 | 只读设备检查、闪存／启动链调查、实际恢复验证 |
| P1 | 无短接手动镜头 | 镜头状态与工厂入口已定位 | 正常快门许可分支、独立状态与镜头回归 |
| P1 | Smart Auto 手动镜头 | 光圈能力相关 UI 路径已定位 | AE 能力判断与实际入射光测光 |
| P1 | 自拍内闪 | 自拍状态切换已定位 | 真正禁闪条件、充电／曝光验证 |
| P1 | 实验菜单 | 237 工厂项已有清单 | 分类语义、菜单入口、写入前值备份与恢复 |
| P2 | PC AutoBackup 到 NAS | 接收端已回放测试 | NX mini 配对、实际格式限制、DSM 联调 |
| P2 | MobileLink／AutoShare 手机接图 | 固件有相关网络线索 | 原厂协议抓取、发现／配对／选图客户端 |
| P2 | 间隔拍摄 | 若可绑定原厂定时／快门任务，改动可能较小；尚未验证 | 定时 API、休眠、张数／电池／写卡状态机 |
| P2 | 曝光包围配置 | 利用已有驱动／曝光设置可行性待查 | 原厂支持范围、步长、RAW 与自动 ISO 行为 |
| P2 | 自动 ISO 最低快门 | 对手动镜头实用；AE 参数格式未知 | AE 决策点、焦距未知时的默认值、用户设置持久化 |
| P2 | 自定义按键／焦距 EXIF | UI 与镜头状态可继续追踪 | 按键派发、设置写入、EXIF 生成与每镜头配置 |
| P2 | 机内风格 JPEG | 存在 IQ 资源，离线接口已建立 | ISP 曲线／矩阵格式、默认状态恢复、色卡标定 |
| P3 | 峰值对焦／放大快捷键 | 现有显示通路能力未知 | 原厂放大接口、预览缓冲格式、CPU 与显示余量 |
| P3 | 斑马纹／高光提示 | 需实时像素处理 | 预览钩子、YUV 布局、帧率与内存预算 |
| P3 | 遥控拍摄 | 与网络路线共用发现和会话 | 实际远程快门接口及拍摄／写卡互斥 |
| P3 | 机内只读 HTTP／FTP | 主机接收服务不能替代机内服务 | REALOS 可执行入口、文件与网络 API、资源预算 |
| P3 | 视频参数调整 | 字符串不足以确定硬件／编码器极限 | 编码器配置、码率／温度／写卡／音画同步验证 |
| P3 | 机内 Quick Share | 协议与资源成本较大，未实现 | 发现、配对、加密传输及现代三星兼容性 |

不提前添加高分辨率／高帧率、RAW 位深或动态范围等无法由现有证据支持的承诺。新增功能先证明原厂通路和资源预算，再决定是否进入补丁实现。
